ArgSense — Help Interface Concepts

Two design directions explored for the help screen: command groups, and an ASCII-art banner.

Concept B · Command Groups (planned) — named groups hold their sub-commands

bash
python -m depsland ...
a package manager for python applications.
COMMAND GROUPS
appmanage applications
├installinstall an app
├upgradeupgrade to the newest version
└runrun an installed app
envmanage the python environment
configinspect and edit configuration
devutilities for developers
run depsland app install -h to see the options of a single command.

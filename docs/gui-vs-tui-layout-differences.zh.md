
ArgSense TUI 和 GUI 在布局细节上存在一些区别, 这是由于二者的不同窗口策略导致的: TUI 的窗口空间往往比较局促, 所以在组件排布时要尽量避免空间浪费 (出现大量空白区域), 所以会有 SmallWidgets 紧凑排列在一行的做法; GUI 的窗口空间则富裕得多, 因此排版就没有那么苛刻.

二者具体差异列举如下.

- GUI 对于 "小组件" 最多支持四个排一行.
- GUI 对于横排的小组件, 按照宽度均分来分配尺寸; TUI 的每个小组件使用自身的宽度
- GUI TextInput:placeholder 不设置; TUI TextInput:placeholder 显示帮助信息 (如果帮助信息为多行, 则只显示第一行)
